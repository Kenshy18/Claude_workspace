# 第2章 価値という考え方 — 台本と演出プラン

目標尺: 約14分。前提: 第1章（MDP, 方策, リターン, 割引, G_t = r_{t+1} + γG_{t+1}）。
この章で腹落ちさせたいこと:
1. 価値 = 「その状態から、その方策で動いたときのリターンの期待値」。方策に依存する。
2. ベルマン方程式は G_t = r + γG_{t+1} の期待値を取っただけ。バックアップ図で「下から上へ平均を集める」。
3. 反復すると必ず収束する（γ-縮小）。値が星と穴から「染み出す」。
4. 行動価値 Q と、貪欲化による方策改善 → 方策反復。
5. ベルマン最適方程式と価値反復。
6. 見せ場: 穴の真下のマスで、矢印がゴールと逆（下）を向く。リスクと時間の天秤。
7. 限界: P を知っている前提／状態数の爆発 → 次章へ。

数値はすべて `common/rl.py` の main_world() から計算して表示すること（ハードコードしない）。
参考値（γ=0.9, slip=0.2）: V*(3,3)≈0.98, V*(0,0)≈0.44, V*(4,1)≈0.39（最適行動は「下」）。
Q*(4,1): 上≈−0.72, 右≈0.22, 下≈0.39, 左≈0.34（実際にコードで計算した値を使う）。
一様ランダム方策の価値: 穴の真下 (4,1) ≈ −0.45、スタート (0,0) ≈ −0.01、星の左 (3,3) ≈ +0.54。

## Scene: StateValue（約2分）
画面: グリッドの (2,1) にロボット。一様ランダム方策で (2,1) から何本もロールアウト（半透明の軌跡を次々描いて消す）。右側に各回のリターン G を縦に積んでいき、その下に「平均」を DecimalNumber で更新（実際の値が V^π(2,1) に近づく）。最後に式。
その後、左右に2枚のヒートマップ:「でたらめな方策」(一様ランダムの V^π) と「賢い方策」(V*)。

N1: あるマスの「良さ」を測る、いちばん素直な方法は何でしょう。
N2: そのマスから何度もスタートして、{A}実際にリターンを測り、{B}その平均を取ることです。
N3: このロボットが、でたらめに動くとしましょう。すると、あるときは星にたどり着き、あるときは穴に落ちる。リターンは毎回ばらばらですが、{A}たくさん集めて平均すれば、ある値に落ち着いていきます。
N4: この平均の行き着く先を、その状態の{A}価値と呼びます。式で書くと、{B}こうなります。状態[s|エス]から出発して、方策パイに従って動いたときの、リターンの期待値です。
  式: V^π(s) = E_π[ G_t | s_t = s ]  （V は VALUE 色、π は POLICY 色）
N5: ここで大事なのは、価値は{A}方策によって変わる、ということです。同じマスにいても、でたらめに動くロボットと、賢く動くロボットとでは、この先の未来が違うからです。
N6: 左は、でたらめな方策の価値。右は、賢い方策の価値です。{A}でたらめに動くと、穴の周りは危険なので、価値がマイナスになっています。

## Scene: Bellman（約2分半）
画面: 上部に G_t = r_{t+1} + γG_{t+1}（第1章の枠付きの式を再登場）。両辺の期待値 → 変形を TransformMatchingTex で。
続いてバックアップ図（Sutton & Barto 風）: 上に状態ノード（白抜き円、青）→ 行動ノード（小さな塗り円、緑、枝に π(a|s)）→ 次状態ノード（青、枝に P(s'|s,a)）→ 葉に r+γV(s')。葉から根へ値が「集まる」アニメーション（点が枝を上る）。
最後に具体例: (3,3)（星の左）を拡大。右を選ぶと 0.8 で星（+1）、0.1 ずつ上の外壁・下の壁にぶつかり滞在。
  V(3,3) = 0.8·1 + 0.2·γ·V(3,3) → 解くと ≈ 0.98（コードの V* と一致することを見せる）

N1: では、価値はどうやって計算すればいいのか。ここで、前回の最後に出てきた、{A}リターンの再帰的な関係が効いてきます。
N2: 両辺の、期待値を取ってみましょう。{A}左辺は、定義により、価値そのものです。
N3: 右辺の、{A}次の時刻からのリターンの期待値は、次の状態がどこになるかさえ分かれば、その状態の価値に置き換えられます。マルコフ性のおかげで、そこから先の未来は、それまでの経緯と関係ないからです。
N4: つまり、{A}あるマスの価値は、一歩進んでもらえる報酬と、行き着いた先のマスの価値のガンマ倍、その平均に等しい。これが、{B}ベルマン方程式です。
N5: 期待値の中身を、きちんと書き下してみましょう。まず、方策に従って行動を選び、次に、遷移確率に従って行き先が決まります。
  式: V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a) [ r + γ V^π(s') ]
N6: 図にすると、こうなります。{A}一番上が、今の状態。そこから、{B}選びうる行動に枝分かれし、それぞれの行動から、{C}滑った先の状態に枝分かれする。一番下の値を、枝の確率で重み付けしながら、下から上へと集めてくる。この操作を、バックアップと呼びます。
N7: 実際の数字で確かめてみましょう。星のすぐ左のマスです。賢い方策は、ここで右を選びます。{A}80%で星に入って、プラス1。{B}残りの20%は、上の外壁か下の壁にぶつかって、その場にとどまります。
N8: おや、{A}右辺にも、このマス自身の価値が出てきました。価値は、ほかのマスの価値、そして自分自身の価値と、方程式でつながっているんです。解いてみると、{B}約0.98。さっきの図の数字と、ぴったり一致します。
N9: 壁と星と穴を除くと、マスは15個。つまりベルマン方程式は、{A}15本の連立方程式です。

## Scene: Evaluation（約2分）
画面: 一様ランダム方策の反復方策評価。ヒートマップ＋数字が 0 から始まり、スイープごとに全マス同時に更新（sweep カウンタ k を左上）。色が星（青緑）と穴（赤）から広がる。
後半: 右側に「真の値からのずれ（最大誤差）」を k に対して対数軸でプロット → 直線。傾き = log γ。
更新式: V_{k+1}(s) ← Σ_a π(a|s) Σ_{s'} P(s'|s,a)[ r + γ V_k(s') ]

N1: この連立方程式は、直接解くこともできますが、もっと面白い解き方があります。
N2: まず、すべてのマスの価値を、{A}0と置きます。もちろん、でたらめな値です。
N3: そして、ベルマン方程式の右辺を使って、{A}すべてのマスの値を、一斉に計算し直します。
N4: これを何度も繰り返すと、{A}星と穴のまわりから、価値がじわじわと染み出していきます。
N5: そしてやがて、ある値に{A}落ち着きます。これが、でたらめな方策の、本当の価値です。この方法を、反復方策評価と呼びます。
N6: なぜ、必ず落ち着くのでしょうか。{A}繰り返すたびに、真の値からどれだけずれているかを、プロットしてみました。縦軸は対数です。
N7: きれいな直線になっています。{A}1回ごとに、ずれが、少なくともガンマ倍に縮むからです。{B}点線は、ちょうどガンマ倍ずつ縮む場合の線。実際のずれは、いつもその下にあります。
N8: 直感的には、こういうことです。1回の更新で、どのマスの値も、報酬という確かな部分と、ガンマ倍された、次のマスの値の部分の和になります。{A}間違っているのは後ろの部分だけで、それは毎回ガンマ倍に縮められる。だから、最初に置いたでたらめな値の影響は、ガンマのk乗で消えていくんです。
N9: こういう性質を持つ写像を、{A}縮小写像と呼びます。出発点がどこであっても、同じ一点に吸い寄せられていく。この性質は、この先、何度も顔を出します。

## Scene: Improvement（約2分）
画面: 一様ランダム方策の Q^π を三角形で表示 → 各マスで最大の三角形を光らせ、矢印に置き換える（貪欲化）。
右側に「評価 → 改善」のループ図（2つのノードを曲線矢印で結ぶ）。方策反復を実際に回し、反復ごとに ヒートマップ（評価）と矢印（改善）を更新。反復回数カウンタ。方策が変わらなくなったら「安定」。
（コードで方策反復を回し、何回で安定するかを確認して台詞の回数を合わせること。現在の世界では改善4回で安定）

N1: ここで、面白いことに気づきます。でたらめな方策の、行動価値を計算したとしましょう。
N2: 各マスで、{A}[Q|キュー]が一番大きい行動だけを選ぶ、新しい方策を作ります。これを、[Q|キュー]に対して貪欲な方策と呼びます。
N3: この新しい方策は、元の方策より、必ず良いか、少なくとも同じです。{A}どのマスでも、一手目を、元の方策より良い手に変えているからです。一手目を良くして、その後も同じように良い手を選び続ければ、悪くなりようがありません。
N4: 新しい方策が手に入ったら、{A}また価値を評価して、{B}また貪欲に改善する。これを繰り返すのが、方策反復です。
N5: やってみましょう。{A}1回目。{B}2回目。{C}3回目。{D}4回目。これ以上改善しようとしても、{E}もう方策は変わりません。
N6: 方策が変わらなくなったとき、その方策は、{A}自分自身の価値に対して、貪欲になっています。実はこれが、最適な方策であるための条件なんです。

## Scene: Optimality（約2分）
画面: ベルマン方程式の Σ_a π(a|s) の部分が max_a に TransformMatchingTex で置き換わる。
価値反復アニメーション: V=0 から、反復 k を左上に。星の隣から価値が広がる。最初の数回はゆっくり（1回/秒）、その後は速く。最後に貪欲な矢印を GrowArrow。
式: V*(s) = max_a Σ_{s'} P(s'|s,a)[ r + γ V*(s') ]

N1: 最適な方策の価値を、{A}[V*|ブイスター]と書きます。最適な方策は、どのマスでも、一番良い行動を選ぶはずです。だから、ベルマン方程式の、方策による平均が、{B}最大値に置き換わります。
N2: これを、ベルマン最適方程式と呼びます。
N3: この右辺を、さっきと同じように、{A}何度も繰り返し当てはめていくのが、価値反復です。評価と改善を、一度にまとめてやってしまうわけです。
N4: 0から始めると、{A}まず、星のとなりのマスだけに、価値が生まれます。{B}次の回には、そのまたとなりへ。星から、価値が波のように広がっていきます。
N5: k回目の値は、あとk歩のうちに得られる、最善の結果、と読むことができます。{A}遠いマスほど、価値が届くのに時間がかかるのは、そのためです。
N6: やがて、値は落ち着きます。{A}最後に、各マスで一番良い行動に矢印を引けば、それが最適方策です。
