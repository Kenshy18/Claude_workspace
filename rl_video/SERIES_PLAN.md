# 強化学習の本質 — シリーズ構成

対象: 教師あり学習（NLP / CV）には慣れているが、強化学習は初めての ML エンジニア。
方針: 3Blue1Brown 流に「具体例 → 直感 → 数式」の順で、各章で1つの大きなアイデアを腹落ちさせる。
画面上の数値（価値、方策、学習曲線など）は `common/rl.py` などで実際に計算したものを使う。

## 通しの題材

- **いつもの世界**: 5×4 のグリッドワールド（`common/rl.py: main_world()`）
  - 左下スタート、右上に星（+1）、その真下に穴（−1）、壁が3つ
  - 床が滑る: 意図した方向に 80%、左右に 10% ずつずれる
  - 割引率 γ = 0.9、途中の報酬は 0
  - 価値反復で求めた最適方策は「穴の近くでは、あえてゴールと逆を向く」＝第2章の見せ場
- **ロボット**: シリーズの主人公（`common/mobjects.py: Robot`）

## 色の約束（`common/style.py`）

状態 s 青 / 行動 a 緑 / 報酬 r 黄 / 価値 V・Q 青緑 / 方策 π 紫 / 割引率 γ 橙 / パラメータ θ 桃

## 章立て

| 章 | タイトル | 中心となるアイデア | 主な式 |
|---|---|---|---|
| 1 | 報酬から学ぶ | 教師あり学習との違い（評価だけ・遅れる報酬・自分でデータを集める）、MDP、方策、リターンと割引、目的関数、「環境は微分できない」 | $G_t=\sum_k\gamma^k r_{t+k+1}$, $J(\pi)=\mathbb{E}[G_0]$ |
| 2 | 価値という考え方 | 状態価値 / 行動価値、リターンの再帰構造 → ベルマン方程式、価値反復で価値が星から染み出す様子、最適方策（穴を避ける矢印） | $V^\pi(s)=\sum_a\pi(a\|s)\sum_{s'}P(s'\|s,a)[r+\gamma V^\pi(s')]$, ベルマン最適方程式 |
| 3 | 経験から学ぶ | 遷移確率を知らないとき。モンテカルロ（平均）→ TD（ブートストラップ）、TD誤差、Q学習と SARSA（崖の例）、探索と活用（ε-greedy） | $V\leftarrow V+\alpha(r+\gamma V(s')-V)$, $Q\leftarrow Q+\alpha(r+\gamma\max Q-Q)$ |
| 4 | 価値をニューラルネットで近似する | 表が使えない世界、関数近似と汎化、DQN の損失、動く標的・相関したデータ → リプレイバッファとターゲットネット、max による過大評価と Double DQN、死の三つ組 | $L(\theta)=(r+\gamma\max_{a'}Q_{\theta^-}(s',a')-Q_\theta(s,a))^2$ |
| 5 | 方策を直接動かす | 方策のパラメータ化（ソフトマックス）、対数微分トリック、REINFORCE ＝「リターンで重み付けした最尤推定」、ベースラインで分散を下げる、アドバンテージ、Actor-Critic | $\nabla J=\mathbb{E}[\sum_t\nabla\log\pi_\theta(a_t\|s_t)\,A_t]$ |
| 6 | 言語モデルを強化学習で鍛える | 大きすぎる更新の危険 → 重要度比と PPO のクリップ、GAE、RLHF（報酬モデル＝ブラッドリー・テリー、KL ペナルティ）、報酬ハッキング、GRPO と検証可能な報酬、全体の地図 | $L^{\rm CLIP}$, $r-\beta\log\frac{\pi}{\pi_{\rm ref}}$ |

## 制作ルール

- ナレーションは `VoiceScene.voice()` に書く（コードが台本の正本）。`tools/transcript.py` で台本を書き出せる。
- 読みが怪しい語は `[表示|よみ]` で読みを指定するか `common/lexicon.py` に登録する。
  `tools/kana_check.py` で全ナレーションの読みを一覧できる。
- 1シーン = 1つの話題。シーンの最後は画面を片付けて（FadeOut）終える。章はシーンをつなげて1本にする。
- 箇条書きスライドにしない。文字は「ラベル」と「式」に絞り、説明は絵と動きで見せる。
