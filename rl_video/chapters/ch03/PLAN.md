# 第3章 経験から学ぶ — 台本と演出プラン

目標尺: 約15分。前提: 第1章（MDP, リターン）、第2章（V, Q, ベルマン方程式, 価値反復, 探索は予告のみ）。
この章で腹落ちさせたいこと:
1. モデルフリー: 手に入るのは (s, a, r, s') の経験だけ。
2. モンテカルロ = 実際のリターンへの回帰（増分平均 = SGD on 二乗誤差）。
3. TD = 1歩先の見積もりで置き換える（ブートストラップ）。TD 誤差 δ。ベルマン方程式のサンプル近似。
4. バイアスとバリアンス（MC はばらつき大・偏りなし、TD はばらつき小・偏りあり）。
5. V ではなく Q を学ぶ理由。SARSA（方策オン）と Q学習（方策オフ）。
6. 探索と活用（3台のスロットマシン、ε-greedy）。
7. 崖歩き（SARSA は安全な道、Q学習は崖っぷち）。
8. いつもの世界で Q学習 → 第2章の最適方策と同じ矢印に（穴の下の「下向き」も）。
9. 表の限界 → 第4章（DQN）へ。

数値・軌跡・学習曲線は、すべて実際にシミュレーションして使う（乱数シードは固定して再現可能に）。
必要なら `chapters/ch03/helpers.py` に崖歩き環境やバンディットを実装する（`common/` は編集しない）。

## Scene: MonteCarlo（約2分）
画面: 左にグリッド、ロボットが (0,0) から固定方策（最適方策にε=0.3の揺らぎ等）で1エピソード走り、終わるとリターン G を表示。
右に数直線（-1〜1）: 現在の推定値 V(s0) のマーカー（青緑の三角）と、新しいサンプル G（黄の点）。マーカーが G の方向へ α の割合だけ動く。これを数十エピソード早回しで繰り返し、真の値（点線）付近に収束していく。
式: V(s) ← V(s) + α ( G − V(s) )
続けて L = ½ (G − V(s))² と、その負の勾配 G − V(s) を並べ、同じ形であることを色で対応づける。

N1: 一番素直なのは、前回の最初にやった方法です。{A}エピソードを最後まで走らせて、実際のリターンを測り、平均を取る。これを、モンテカルロ法と呼びます。
N2: 平均は、全部のデータを取っておかなくても、{A}一つずつ更新できます。新しいリターンが届くたびに、今の推定値を、その方向へ、少しだけ動かすんです。
N3: 動かす割合の、アルファは、学習率です。{A}この式、どこかで見覚えがありませんか。
N4: そう。これは、{A}推定値と、観測したリターンとの二乗誤差を、勾配降下で小さくする更新、そのものです。リターンを正解ラベルとみなした、回帰なんです。
N5: ただし、モンテカルロ法には、弱点が二つあります。{A}一つは、エピソードが終わるまで、何も学べないこと。{B}もう一つは、リターンのばらつきが大きいことです。途中で振られた、たくさんのサイコロの目が、全部リターンに積み重なるからです。

## Scene: TD（約2分半）
画面: 横一列のエピソードのタイムライン（s0 a0 r1 s1 …）。MC はエピソード末尾で一度だけ更新（矢印が最後から全体へ）。TD は1ステップごとに、その場で更新（各ステップで小さなフラッシュ）。
式変形: V(s) ← V(s) + α ( G − V(s) ) の G が TransformMatchingTex で r + γV(s') に変わる。
括弧の中に Brace で「TD誤差 δ」。
最後に、第2章のバックアップ図（全分岐）→ 実際に起きた1本の枝だけ残してほかを薄くする（サンプル近似）。

N1: そこで、発想を変えます。エピソードの最後まで待つ代わりに、{A}一歩だけ進んで、そこで判断するんです。
N2: 一歩進むと、{A}報酬と、次の状態が分かります。そこから先のリターンは、まだ分かりません。でも、その見積もりなら、手元にあります。{B}次の状態の、価値の推定値です。
N3: そこで、モンテカルロ法の[G|ジー]を、{A}報酬、足す、ガンマ倍の、次の状態の価値、で置き換えます。
N4: これが、TD学習です。TDは、テンポラル・ディファレンス、時間的な差分の略です。{A}括弧の中身、一歩先から見た見積もりと、今の見積もりとの差を、TD誤差と呼び、デルタで表します。
N5: 推定値を使って、推定値を更新する。{A}自分の靴紐を引っ張って、自分を持ち上げるような、この方法を、ブートストラップと呼びます。一見インチキのようですが、ちゃんと、ベルマン方程式の解に収束します。
N6: 実はこれは、前回のバックアップの、{A}すべての枝の平均の代わりに、{B}実際に起きた一本の枝だけを使ったもの、と見ることもできます。遷移確率を知らなくても、実際の経験が、その代わりをしてくれるわけです。

## Scene: BiasVariance（約1分半）
画面: あるマス（例: (2,1)）、固定方策での2つのヒストグラムを上下に:
 上: MC の目標 G のサンプル分布（広い、プラスとマイナスの2つの山）
 下: TD の目標 r + γV(s') のサンプル分布（V は真の値を使う → 狭い）
両方に真の V(s) を縦の点線で。サンプルを落として積み上げるアニメーション（数百サンプル、実際に計算）。
後半: 「今の推定値がずれていると TD の目標もずれる」: 下のヒストグラム全体が横にずれる演出。

N1: モンテカルロと、TD。二つの目標を、同じマスで比べてみましょう。
N2: {A}モンテカルロの目標、つまり実際のリターンは、こんなふうに、大きくばらつきます。星にたどり着く回もあれば、穴に落ちる回もあるからです。
N3: {A}TDの目標は、一歩分のばらつきしか含まないので、ずっと狭い範囲に収まります。
N4: その代わり、TDの目標は、{A}今の推定値が間違っていると、そのぶん、ずれてしまいます。偏り、つまりバイアスがあるわけです。
N5: ばらつきは大きいけれど、偏りのないモンテカルロ。ばらつきは小さいけれど、偏りうるTD。{A}実は、何歩か進んでから見積もる、中間の方法もあります。この考え方は、最終章で、もう一度登場します。

## Scene: Control（約2分半）
画面: 「V から Q へ」: V のヒートマップ → 三角形の Q 表示へ変形。
SARSA 式 → Q学習 式（違う部分 Q(s',a') と max_{a'} Q(s',a') を強調して TransformMatchingTex）。
方策オン/オフの図: ロボットの実際の足取り（ときどき寄り道＝ε）と、Q学習が「想定する」足取り（常に最善）を、実線と点線で重ねる。

N1: さて、価値が分かっても、それだけでは動けません。前回は、遷移確率を使って、どの行動が良いかを計算しました。でも、今は、その遷移確率がありません。
N2: そこで、{A}最初から、行動価値[Q|キュー]を学ぶことにします。[Q|キュー]なら、遷移確率がなくても、{B}一番大きな値の行動を選ぶだけで済みます。
N3: TD学習を[Q|キュー]に当てはめると、{A}こうなります。次の状態で、実際に選んだ次の行動の[Q|キュー]を使う。状態、行動、報酬、状態、行動の頭文字をとって、{B}[SARSA|サルサ]と呼ばれます。
N4: もう一つの選択肢は、{A}次の状態で、一番大きな[Q|キュー]を使うことです。これが、{B}Q学習です。
N5: 違いは、たったこれだけ。でも、意味は大きく違います。{A}[SARSA|サルサ]は、自分が実際に取る行動の、価値を学びます。{B}Q学習は、次からは最善の行動を取る、と仮定した価値、つまり、最適な行動価値を学びます。実際の行動が、ときどき寄り道していたとしても、です。
N6: 前者を、方策オン型、後者を、方策オフ型と呼びます。{A}Q学習は、ベルマン最適方程式を、経験から、一回ずつ近似しているわけです。

## Scene: Exploration（約2分）
画面: 3台のスロットマシン（角丸長方形＋レバー、上に「?」）。真の当たり確率（例 0.3, 0.5, 0.8）は最初は隠す。下に各台の推定値の棒と、回した回数。

（シミュレーションは実際に回し、上の筋書きになるシードを選ぶ）

N5: こうすると、{A}最初は運が悪くても、いずれ、右の台の良さに気づくことができます。
N6: 知っていることを使って稼ぐか、知らないことを調べに行くか。{A}強化学習のエージェントは、いつも、このジレンマの中で行動しています。
