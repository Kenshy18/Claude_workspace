# 第4章 価値をニューラルネットで近似する（DQN） — 台本と演出プラン

目標尺: 約14分。前提: 第3章（TD, Q学習, 方策オフ, ε-greedy）。視聴者は CNN / 教師あり学習に詳しい。
この章で腹落ちさせたいこと:
1. 表の限界と「汎化」: 似た状態は似た価値 → 関数近似。
2. Q ネットワーク = 分類器と同じ形の出力層（行動ごとの出力）だが、中身は回帰。
3. DQN の損失 = TD 目標をラベルにした回帰。ラベルは定数扱い（stop-gradient）。
4. 教師あり学習との決定的な違い:「ラベルが自分の出力と一緒に動く」「データが相関していて i.i.d. でない」
   → ターゲットネットワーク、経験リプレイ。
5. max による過大評価（ノイズの最大値は上に偏る）→ Double DQN。
6. 死の三つ組（関数近似＋ブートストラップ＋方策オフ）と、2状態の発散例。
7. 価値ベースの限界（行動が連続・巨大だと max が取れない）→ 第5章へ。

図の数値（過大評価のヒストグラム、2状態の発散など）は実際に計算する。
Atari の画面は著作物を使わず、ブロック崩し「風」の図形を自作する（色付きの長方形のブロック、パドル、ボール）。
必要なら `chapters/ch04/helpers.py` を作る（`common/` は編集しない）。

## Scene: Generalization（約2分）
画面: 横軸が1次元の連続状態（例: パドルの位置 0〜1）、縦軸が価値。
(1) 表: 訪れた数点にだけ棒が立ち、訪れていない位置は空白。
(2) 関数近似: 同じ点を通る滑らかな曲線（小さなMLPで実際にフィット、あるいは多項式回帰）。訪れていない位置の値も曲線から読める。
(3) 1点の更新が近くの値も動かす: ある点のターゲットを上げると、曲線がその周辺ごと持ち上がる（パラメータ共有）。

N1: 鍵になるのは、{A}汎化です。
N2: 表では、ある状態で学んだことは、{A}その状態にしか反映されません。ほんの少しだけ違う状態は、まったくの別物として扱われます。
N3: そこで、価値を、{A}パラメータを持つ関数で表します。すると、似た状態には、自然と似た価値が割り当てられ、{B}一度も訪れていない状態の価値も、推測できるようになります。
N4: 裏を返すと、{A}一つの状態の値を動かすと、そのまわりの値も、一緒に動いてしまいます。これが、あとで問題の種になります。覚えておいてください。

## Scene: QNetwork（約1分40秒）
画面: 入力（4枚重ねのピクセル画像）→ 畳み込み層（台形のブロック数個）→ 全結合 → 出力は行動ごとの棒（左・そのまま・右 など3〜4本、数値付き）。出力の棒が「分類器の logits の位置」にあることを示す。
式: Q_θ(s, a)（θ はTHETA色）

N1: [DQN|ディーキューエヌ]のネットワークは、見た目は、画像分類のモデルとそっくりです。
N2: {A}画像を畳み込み層に通して、最後に、{B}行動の数だけ出力を出します。分類なら、ここはクラスごとのスコアでした。
N3: ただし、ここに出てくるのは、{A}確率ではなく、それぞれの行動を取ったときの、リターンの見積もり、つまり行動価値です。分類ではなく、回帰なんです。
N4: 行動を選ぶときは、{A}一番大きな出力を選ぶだけ。一回の計算で、全部の行動の価値が出てくるように作ってあるわけです。

## Scene: Loss（約2分）
画面: Q学習の更新式 → 損失関数へ変形。
  Q学習: Q(s,a) ← Q(s,a) + α ( r + γ max_{a'} Q(s',a') − Q(s,a) )
  DQN:  y = r + γ max_{a'} Q_θ(s', a')   L(θ) = ( y − Q_θ(s, a) )²
y を「ラベル」として黄色の枠、Q_θ(s,a) を「予測」として青緑の枠。y 側に「定数とみなす（勾配を流さない）」の注記（stop-gradient 記号や鍵アイコン）。
教師あり学習の損失 (y − f_θ(x))² を上に並べて、同じ形であることを強調。

N1: では、どうやって学習するのか。前回のQ学習の更新式を、思い出してください。
N2: 括弧の中は、{A}目標の値と、今の見積もりの差でした。そこで、{B}この目標を「ラベル」とみなして、二乗誤差を小さくする回帰問題にします。これが、[DQN|ディーキューエヌ]の損失関数です。
N3: 教師あり学習の、見慣れた形と{A}そっくりですね。ただし、決定的に違うところがあります。
N4: {A}ラベルの中に、学習しているネットワーク自身が、入っているんです。
N5: 勾配を計算するときは、{A}ラベルの側は、定数とみなします。ラベルの側まで微分してしまうと、目標そのものを、予測に近づけてしまうからです。

## Scene: MovingTarget（約2分）
画面: 1次元の数直線（または2Dの平面）上に、予測（青緑の点）と目標（黄の点）。
(1) ターゲットネットなし: 予測が目標へ動くと、目標も一緒に動く（y が θ に依存）→ 追いかけっこ、行き過ぎて振動する様子。
(2) ターゲットネットあり: 目標を固定（鍵マーク、「θ⁻」）。予測がそこへ収束 → 一定ステップごとに目標がジャンプ（階段状）。
下部に、損失の推移の小さなグラフ（(1) は暴れ、(2) は下がってはジャンプを繰り返しつつ全体として落ち着く）。可能なら小さなトイ問題で実際に計算。
式: y = r + γ max_{a'} Q_{θ⁻}(s', a')

N1: ラベルが、自分と一緒に動くと、何が起きるでしょうか。
N2: 予測を{A}目標に近づけようと、パラメータを動かすと、{B}同じパラメータを使っている目標も、一緒に動いてしまいます。前に話した、汎化のせいです。
N3: まるで、自分の影を追いかけるようなもので、{A}学習が振動したり、ときには発散したりします。
N4: そこで[DQN|ディーキューエヌ]は、{A}目標を計算するためだけの、ネットワークのコピーを用意します。ターゲットネットワークです。
N5: コピーのパラメータは、しばらくのあいだ{A}固定しておき、数千ステップごとに、{B}最新のパラメータで上書きします。その間は、ラベルが動かないので、普通の回帰問題として、落ち着いて学習できるわけです。

## Scene: Replay（約1分40秒）
画面: フィルムストリップのように連続したフレーム（ほとんど同じ絵）が流れてくる。
(1) そのまま順に学習すると、ミニバッチの中身がほぼ同じ → 右側の「分布」が偏る。
(2) リプレイバッファ（大きな棚、カードが並ぶ）に経験 (s, a, r, s') を次々と入れる。古いものから押し出される。
(3) バッファからランダムに32枚を抜き出してミニバッチにする（散らばった位置のカードが光って集まる）。

N1: もう一つの問題は、{A}データの性質です。
N2: ゲームを遊びながら集めた経験は、{A}時間の順に並んでいて、隣り合う場面は、ほとんど同じです。確率的勾配降下法が前提にしている、独立で同じ分布から来たデータ、とは、ほど遠いんです。
N3: そのまま順番に学習すると、{A}今いる場面のことばかり覚えて、前に学んだことを、忘れてしまいます。
N4: そこで、{A}経験を、いったん大きなバッファに貯めておき、{B}学習のときは、そこからランダムに取り出してミニバッチを作ります。経験リプレイです。
N5: これで、ミニバッチの中の相関が断ち切られ、{A}しかも、同じ経験を何度も使い回せるので、データの無駄も減ります。Q学習が、方策オフ型だからこそ使える手です。古い方策で集めたデータからでも、学べるからです。

## Scene: Overestimation（約2分）
画面: 4つの行動。真の価値はすべて0（点線）。推定値はノイズ付き（毎回ランダムに揺れる棒）。
各回、最大の棒を光らせ、その値を右のヒストグラムに積み上げる → 平均が0より明らかに大きい（4本の標準正規なら約+1.03。実際に数千回サンプリングして表示）。
Double DQN: 推定を2組（オンライン用とターゲット用、独立なノイズ）。選ぶのは片方、値を読むのはもう片方 → ヒストグラムの平均が0付近に戻る。
式: y = r + γ Q_{θ⁻}( s', argmax_{a'} Q_θ(s', a') )

N1: [DQN|ディーキューエヌ]には、もう一つ、見落としやすい落とし穴があります。{A}目標の中の、マックスです。
N2: 四つの行動の、本当の価値が、{A}全部0だったとしましょう。でも、推定値には、誤差があります。{B}たまたま大きく見積もられた行動が、毎回一つくらいはあります。
N3: マックスは、{A}その「たまたま大きい」ものを、選んでしまいます。何度も繰り返すと、平均は0ではなく、{B}プラスに偏ります。ノイズの最大値は、上に偏るんです。
N4: しかも、この偏った値が、次の目標として使われ、{A}ブートストラップで、ほかの状態にも伝わっていきます。
N5: 対策は、意外なほど簡単です。{A}どの行動を選ぶかは、学習中のネットワークで決めて、{B}その行動の値は、ターゲットネットワークで読む。選ぶ役と、評価する役を分けると、誤差が同じ方向にそろわなくなり、偏りが消えます。{C}これを、ダブル[DQN|ディーキューエヌ]と呼びます。

## Scene: Algorithm（約1分）
画面: 全体図。環境 → （ε-greedy で行動）→ 経験をリプレイバッファへ → ランダムにミニバッチ → オンラインネット Q_θ と ターゲットネット Q_{θ⁻} → 損失 → θ を更新 → 数千ステップごとに θ⁻ ← θ。
各部品を順番にハイライトしながら、ナレーションで一巡。

N1: ここまでの部品を、組み立ててみましょう。
N2: {A}ロボットは、イプシロン・グリーディで行動し、{B}経験をリプレイバッファに貯めます。{C}そこからランダムにミニバッチを取り出し、{D}ターゲットネットワークで目標を計算して、{E}二乗誤差を小さくするように、ネットワークを更新する。{F}そして、ときどき、ターゲットネットワークに重みをコピーする。
N3: 2015年に発表された[DQN|ディーキューエヌ]は、この仕組みで、{A}49種類のゲームを、同じネットワーク構造、同じ設定のまま、画面の画素だけから学習し、その多くで、人間のプロのテスターに匹敵するスコアを出しました。

## Scene: DeadlyTriad（約1分40秒）
画面: 2状態の例。状態 s1 の価値 = θ、状態 s2 の価値 = 2θ（パラメータ共有）。s1 → s2 へ報酬0で遷移。
s1 だけを繰り返し更新すると（方策オフ的な偏ったデータ）、θ ← θ + α(γ·2θ − θ) = θ(1 + α(2γ − 1))。γ > 0.5 なら θ は指数的に増大。
θ の値をグラフで表示し、発散していく様子を実際に計算して描く。
右に3つの要素のベン図（関数近似・ブートストラップ・方策オフ）、中央が赤く「発散しうる」。

N1: 最後に、少し怖い話をしておきます。
N2: ここに、{A}たった二つの状態があるとします。左の価値はシータ、右の価値は、その2倍。{B}一つのパラメータを共有しています。左から右へは、報酬0で移ります。
N3: 左の状態で、TD学習をしてみます。目標は、ガンマ倍の、右の価値、つまり{A}2ガンマ・シータ。今の値はシータなので、ガンマが0.5より大きいと、シータは、{B}大きくなる方向へ動きます。
N4: でも、シータが大きくなると、{A}右の価値も大きくなり、目標も、もっと大きくなる。本来なら、右の状態でも学習して、つじつまが合うはずですが、右のデータが来なければ、{B}シータは、どこまでも大きくなってしまいます。
N5: 関数近似、ブートストラップ、そして方策オフ。{A}この三つがそろうと、学習は発散しうる。死の三つ組と呼ばれています。[DQN|ディーキューエヌ]の工夫は、この危うい組み合わせを、実用上なんとか手なずけるためのもの、とも言えます。
